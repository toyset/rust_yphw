# Quote Service

CLI-приложения для периодической отправки и приема биржевых котировок по протоколам TCP и UDP.

## Описание

Проект состоит из двух приложений:

- **Сервер** (`quote_server`) — принимает TCP-соединения от клиентов, периодически генерирует котировки для заданных тикеров и рассылает их по UDP.
- **Клиент** (`quote_client`) — подключается к серверу по TCP, отправляет список интересующих тикеров и принимает котировки по UDP.

## Установка

### Требования

- Rust (последняя стабильная версия)
- Cargo

### Сборка

```bash
cargo build --release
```

Исполняемые файлы будут находиться в `target/release/`

## Использование

### Сервер

Запуск сервера с чтением тикеров из файла:

```bash
quote_server --tickers-file tickers.txt
```

#### Параметры командной строки

| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| `--ip` | IP адрес сервера | `127.0.0.1` |
| `--tcp-port` | TCP порт сервера | `34254` |
| `--udp-port` | UDP порт для рассылки котировок | `34255` |
| `--client-timeout-ms` | Максимальное время ожидания пинга от клиента (мс) | `2000` |
| `--update-period-ms` | Период обновления котировок (мс) | `2000` |
| `-f, --tickers-file` | Путь к файлу с тикерами | **Обязательный** |

#### Пример запуска

```bash
quote_server \
    --ip 0.0.0.0 \
    --tcp-port 8080 \
    --udp-port 8081 \
    --update-period-ms 1000 \
    --client-timeout-ms 5000 \
    --tickers-file ./data/tickers.txt
```

### Клиент

Запуск клиента с подключением к серверу:

```bash
quote_client --tickers-file tickers.txt
```

#### Параметры командной строки

| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| `--server-ip` | IP адрес сервера | `127.0.0.1` |
| `--server-port` | TCP порт сервера | `34254` |
| `--client-ip` | IP адрес клиента (для приема UDP) | `127.0.0.1` |
| `--client-port` | UDP порт клиента | `34256` |
| `-f, --tickers-file` | Путь к файлу с тикерами | **Обязательный** |

#### Пример запуска

```bash
quote_client \
    --server-ip 192.168.1.100 \
    --server-port 8080 \
    --client-ip 192.168.1.50 \
    --client-port 9000 \
    --tickers-file ./data/tickers.txt
```

## Формат файла с тикерами

Файл должен содержать по одному тикеру на строку. Пустые строки игнорируются.

Пример `tickers.txt`:

```
AAPL
GOOGL
MSFT
TSLA
AMZN
```

## Логирование

Оба приложения используют `env_logger`. Для включения подробного логирования установите переменную окружения:

```bash
# Linux/macOS
export RUST_LOG=debug

# Windows (CMD)
set RUST_LOG=debug

# Windows (PowerShell)
$env:RUST_LOG="debug"
```

## Остановка приложений

- **Сервер**: для остановки нажмите `Ctrl+C`.
- **Клиент**: для остановки нажмите `Ctrl+C` — клиент корректно завершит работу.

## Протокол взаимодействия

1. Клиент подключается к серверу по TCP.
2. Клиент отправляет список тикеров.
3. Сервер периодически (с интервалом `update_period_ms`) генерирует котировки и рассылает их по UDP всем подключенным клиентам.
4. Клиент отправляет периодические ping-сообщения для поддержания соединения.
5. Если сервер не получает ping от клиента в течение `client_timeout_ms`, соединение закрывается.

## Обработка ошибок

- Приложение завершается с ошибкой, если файл тикеров пуст или не может быть прочитан.
- Ошибки подключения и потери соединения логируются.
